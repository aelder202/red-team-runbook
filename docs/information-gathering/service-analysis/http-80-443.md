## Quick Service Fingerprint

The first thirty seconds on any HTTP(S) port:

```bash
curl -sI http://$IP                             # HTTP headers
curl -skI https://$IP                           # HTTPS headers
whatweb http://$IP                              # tech stack fingerprint
nmap -p 80,443 -sV --script http-enum,http-title,http-methods,http-headers $IP
```

For TLS inspection and cert SAN extraction (SAN entries often reveal other vhosts):

```bash
openssl s_client -connect $IP:443 -showcerts </dev/null 2>/dev/null \
  | openssl x509 -noout -text | grep -E 'Subject:|DNS:'
```
